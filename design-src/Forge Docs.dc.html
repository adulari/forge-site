Mesh routing

You don't pick a model; you connect providers and let Forge pick. Every task is classified into a tier, then routed to the cheapest model that meets the bar, ranked against real Artificial Analysis intelligence and coding scores.

Failover rules

429 rate limit · a per-minute free-tier reset is waited out and the best model retried, not immediately downgraded.
transient 5xx · retried on the same model with bounded backoff.
permanent errors · no tool support, 402 payment-required: fail over at once, down the whole ranked catalog, across providers.

Budgets and conservation

[mesh] daily_budget_usd = 5.0 monthly_cap_usd = 50.0 credit_mode = "strict" # free + subscription only, never a paid key

Under budget pressure, or to spare a metered plan, the mesh spreads standard and complex work onto free frontier models. Auto-downshift kicks in as caps approach.

The /effort knob

low · medium · high · xhigh · white-hot. It steers the whole route, not just a provider's reasoning parameter: higher effort biases toward stronger-benchmarked models only when the score gap is real. White-hot adds automatic workflow-script orchestration on top of maximum reasoning.

Benchmarks

The honest test of a harness: run the same model through Forge and through the raw vendor CLI, and let the official evaluator score both. The harness is the only variable.

Method

SWE-bench Lite (real GitHub bug fixes). The same claude sonnet runs through Forge's bridge vs. the raw claude CLI, scored by the official swebench Docker evaluator.

Forge strictly dominates: every bug the raw CLI fixed, Forge also fixed, plus two more, zero the other way, at ~21% lower token cost per fix. The larger N=20 run holds the same direction (11 vs 9). Total tokens are at parity: Forge does more work because it solves more.

Why the gap exists

Real models loop, write tool calls as prose that never execute, and claim "done" without checking. Forge's loop gates completion on tool-grounded evidence, recovers orphaned tool calls, and guards against doom loops; 324 conformance tests pin those behaviors.

Subscriptions & OAuth

Run the plan you already pay for through Forge and get mesh routing, failover, and the reliability layer on top. No other agent does this.

Two ways in

native OAuth Codex (paste-redirect or RFC 8628 device flow) and Grok / xAI. Fully headless, state + PKCE verified, tokens in the OS keyring. Native model use, no CLI in the loop. CLI bridge Claude Code and Antigravity ban third-party OAuth credential use, so Forge drives their official CLI instead. Your plan still gets routing, conservation, and the completion gate.

How it works

A persistent bridge transport keeps Claude re-drives warm; CLIs without that support fall back to a safe one-process-per-turn path that never double-executes tools.
Headless OAuth for Codex (paste-redirect or device flow) and xAI, with PKCE verification. Secrets live in the OS keyring.
Subscription conservation spreads trivial and standard work onto free models so your metered quota is spent only where it matters. credit_mode = "strict" keeps routing free + subscription only.
Proof this works: the same sonnet fixes 50% more SWE-bench bugs through Forge than through the raw CLI. See Benchmarks.

Workflows & automation

Fan work out, race models against each other, and let Forge work while you sleep.

/workflow · scripted orchestration

Sandboxed JS scripts compose agent(), parallel(), and pipeline() into phases of mesh-routed agents, rendered live in a dedicated animated dashboard. Save scripts and re-run them by name.

/duel · the arena

Race up to 3 distinct-provider models on the same task in parallel git worktrees, review, merge the winner. Recorded wins feed back into routing: forge scoreboard shows what your repo has taught the router.

forge queue · overnight autopilot

Queue tasks by day; drain them headless overnight, each in an isolated worktree, killed at its budget cap and optionally assay-gated. Wake up to review-ready autopilot branches and a morning digest.

${{ c.cmd }}{{ c.note }}{{ c.label }}
forge schedule registers recurring headless runs on native OS timers (systemd, launchd, Task Scheduler); point one at forge queue run for a nightly drain. Assay adds a parallel adversarial critic crew with a CI gate (forge assay run --scope diff --fail-on high).

Apps & remote control

Every surface drives the same sessions, permissions, plans, and audit trail: terminal, desktop app, phone, or any OpenAI SDK.

forge serve · the fleet daemon

One headless process, any number of sessions, all driveable from a phone or browser at a stable origin (default port 7420). Sessions survive disconnects; reconnects replay what you missed. Push notifications carry Allow/Deny actions you can answer from the lock screen.

The Tauri desktop app auto-discovers your Forge install and checks signed updates. The companion app (one TypeScript codebase for iOS, Android, Web, Windows, macOS, Linux) ships fleet, inbox, plans, review, replay, usage, models, and configuration as native screens, plus voice capture and iOS Live Activities. Fastest mobile install: open the forge serve URL and Add to Home Screen.

forge api · OpenAI-compatible server

Point any OpenAI SDK at http://127.0.0.1:8787/v1 and use model auto to route each request through the mesh: streaming, tool calls, JSON schemas, and routing/cost metadata included.

MCP & skills

MCP client (stdio + HTTP/SSE, OAuth) and MCP server in one. Skills and commands are Claude Code format compatible: forge import claude migrates your existing setup, forge skill install owner/repo pulls from GitHub, and forge migrate packs a whole install to move machines.

Config layers

Everything is editable in-app with /config: fuzzy-search any setting, permission rules, keybinds, hooks, statusline. Changes validate and persist.

Telemetry

Anonymous counters only: no prompts, responses, file contents, paths, repo names, keys, or stable identifiers. It never blocks Forge, and one line disables it everywhere:

[telemetry] enabled = false
