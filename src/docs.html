Install Forge

Install from crates.io when Rust is available:

❯ cargo install forge-agent

Release binaries and additional platform instructions are maintained in the Forge installation guide.

Connect a provider

Run the interactive provider setup and choose an API key, local Ollama endpoint, or a supported subscription bridge. Credentials are stored in the operating-system keyring rather than config.toml.

❯ forge provider add

You can connect more than one provider. The Mesh ranks eligible models and fails over across the configured catalog.

Start a session

Change into a repository and launch Forge. Review the initial permission policy before allowing commands or file changes.

❯ cd my-project && forge

Inside a session, use /mesh to inspect routing, /workflow to run a typed workflow, and ? to open the current key reference.

Useful commands

forge serve

Expose the local Forge API for the web or mobile controller.

forge doctor

Check providers, credentials, configuration, and local dependencies.

forge bench swe

Run the reproducible SWE-bench harness evaluation.

forge anywhere

Log in, enroll devices, connect hosts, inspect quota, hand off work, and manage the optional hosted companion.

Choose a remote path

Local and LAN controllers, direct pairing, and a tunnel you manage remain free. Forge Anywhere adds a managed encrypted relay, stable host identities, sync, remote jobs, workspace handoff, and replay links.
