The Mesh. You connect providers.

Every task is classified into a tier, then routed to the cheapest model that meets the bar, benchmark-ranked against real intelligence and coding scores.

Reset-aware failover

A per-minute 429 is waited out, not downgraded. Real outages fail over down the ranked catalog across providers.

Subscription conservation

Spreads load onto free frontier models so your metered Claude or Codex quota is spent only where it matters.

Key stacking

Add multiple keys per provider and Forge round-robins across them, multiplying available free-tier rate limits.

Not a wrapper. A full workshop.

Forge carries the context, proof, memory, and recovery machinery a long-running coding session needs.

Code intelligence

A tree-sitter symbol graph across nine languages: blast radius, call chains, semantic retrieval, and relevant context before every turn.

Provenance

Trace a line back to the model, session, prompt, and reasoning that wrote it. Replay the session or fork a counterfactual.

Model races

Race three models on one task in parallel worktrees, merge the winner, and let routing learn from recorded wins.

Durable workflows

Queue tasks, drain them headless into isolated worktrees, and return to review-ready branches with a digest.

Project memory

Typed facts per project are captured at turn end and relevance-ranked back into the next session.

Completion you can verify

Tool-grounded gates, doom-loop guards, and recovery for malformed tool calls stop phantom success reports.

The practical questions.

Why AGPL-3.0?

So Forge stays open: anyone can read, audit, and improve the harness, and improvements flow back instead of disappearing into closed forks.

Is Forge really free?

Yes. Forge is a free static binary with zero paid keys required. Connect free-tier providers or bridge a subscription you already pay for. Forge Anywhere is a separate optional service.

How can I support Forge?

Star the Forge repository, file issues, or sponsor development.
